Live earthquake globe

JavaScript, globe.gl, three.js, service worker

Every earthquake USGS reports, shown on a 3D globe and refreshed each minute. It replays the last day or month, estimates how strong the shaking was where you are, and keeps working offline. No backend and no API key.

Forth interpreter in C

C11, no dependencies

One C file. Each line is compiled to a set of twelve opcodes and run on a small virtual machine. The REPL shows the stack after every command, and a turtle draws in the terminal with braille characters.
